# 史鉴智师 · 初中历史教学智能体（Web 应用）

以史为鉴、以智为师——面向统编版初中历史教材的学科教学智能体，聚焦 **智能备课、习题生成、家校沟通** 三大教学辅助场景，内置知识库 + AI 大模型（DeepSeek）双轨驱动。纯静态零依赖，浏览器打开即用。

## 快速开始

### 环境要求

- 任意现代浏览器（Chrome / Edge / Firefox / Safari，含手机端）
- 无需安装任何依赖（纯前端静态站点）

### 安装与运行

```bash
# 方式一：直接双击 index.html 即可使用

# 方式二：本地服务器（推荐，便于分享到局域网）
cd shijian-app
python -m http.server 18080
# 浏览器访问 http://localhost:18080

# 方式三：公网分享（SSH 隧道，免账号）
ssh -R 80:localhost:18080 nokey@localhost.run
```

## AI 增强（可选，任意场景自由生成）

三大模块均支持接入 DeepSeek 大模型，突破内置内容限制：

- **任意课目备课**：输入任意课目/知识点，AI 按「课标定位—素养目标—史料情境—问题链—分层作业」生成完整教案
- **任意课目组卷**：输入任意课目/知识点，AI 按基础/提升/拓展三层命制带答案与解析的分层习题
- **任意家校文案**：输入通知/文案需求，AI 生成规范、得体、脱敏的家长文案，可复制到班级群

使用方式：

- 在各模块页顶部「AI 增强」卡片中填入 DeepSeek API Key（仅保存在本机浏览器，不上传作品）
- 未配置 Key 时自动使用内置统编版知识库与模板，离线可用
- API Key 申请：https://platform.deepseek.com （官方提供免费额度）

## 技术栈

- 原生 HTML / CSS / JavaScript（零框架、零依赖、零构建）
- 内置学科知识库：9 个课目、45 道分层题目（含判分点与错因标签）、家校沟通模板
- 可选 AI：DeepSeek 大模型（浏览器前端直连，OpenAI 兼容格式）
- 知识内容依据：统编版《中国历史》七—九年级教材、《义务教育历史课程标准（2022 年版）》
