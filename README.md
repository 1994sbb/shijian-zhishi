# 史鉴智师 · 初中历史教学智能体（Web 应用）

以史为鉴、以智为师——面向统编版初中历史教材的学科教学智能体，知识库、工作流、插件三重驱动，覆盖备课、命题、批改、学情、答疑、规划、家校沟通全流程。纯静态零依赖，浏览器打开即用。

## 快速开始

### 环境要求

- 任意现代浏览器（Chrome / Edge / Firefox / Safari，含手机端）
- 无需安装任何依赖（纯前端静态站点）

### 安装与运行

```bash
# 方式一：直接双击 index.html 即可使用

# 方式二：本地服务器（推荐，便于分享到局域网）
cd shijian-app
python -m http.server 18080
# 浏览器访问 http://localhost:18080

# 方式三：公网分享（SSH 隧道，免账号）
ssh -R 80:localhost:18080 nokey@localhost.run
```

## 功能清单

| 模块 | 路由 | 功能 |
|------|------|------|
| 首页 | #/home | 角色入口 + 九大功能矩阵 + 架构摘要 |
| 智能备课 | #/prep | WF1 工作流：课标定位→学情预读→教案生成→史料匹配→分层作业，导出 Word |
| 习题生成 | #/exam | 知识点 × 难度 × 题型三维组卷，含判分点、解析、错因标签，导出 Word |
| 作业批改 | #/grading | WF2 工作流：模拟 OCR 识别→判分点对齐逐题批改→个性化评语→错因归类 |
| 学情分析 | #/analytics | 知识点热力图 + 素养雷达图 + 共性错因分布 + 教学建议，导出报告 |
| 启发式答疑 | #/tutor | 苏格拉底式追问引导→思路支架→变式题（答案锁定至提交后解锁） |
| 错题本 | #/mistakes | 四类错因（概念混淆/审题偏差/表达不规范/时序错乱）归档 + 补强练习 |
| 复习规划 | #/plan | WF4：按薄弱维度生成周计划与中考三轮总规划 |
| 历史时间轴 | #/timeline | 朝代轴 / 近代大事轴双模式交互（时间轴插件） |
| 家校沟通 | #/family | 三大场景文案模板（学情通报/分层作业说明/活动邀请），一键复制 |

## 目录结构

```
shijian-app/
├── index.html          # 入口（hash 路由 SPA）
├── css/style.css       # 宣纸/赭石设计系统
├── js/
│   ├── data.js         # 学科知识库（课目/课标/史料/题库/批改样本/学情/时间轴/模板）
│   ├── app.js          # 路由与公共工具（Word 导出、复制等）
│   ├── teacher.js      # 首页 + 教师端四页
│   ├── student.js      # 学生端三页
│   └── tools.js        # 时间轴 + 家校沟通插件
└── README.md
```

## 技术栈

- 原生 HTML / CSS / JavaScript（零框架、零依赖、零构建）
- 内置学科知识库：9 个课目、45 道分层题目（含判分点与错因标签）、批改样本与学情数据
- 知识内容依据：统编版《中国历史》七—九年级教材、《义务教育历史课程标准（2022 年版）》
